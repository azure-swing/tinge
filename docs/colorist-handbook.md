# 调色参考手册（可选）

用于风格设计、偏色排查或用户要求按调色师方法处理时。普通曝光修正、
格式检查和导出可跳过。本文是 Tinge 的原创实践笔记和官方阅读索引，
不是第三方教材全文，也不是必须照抄的预设。无需联网即可使用这些笔记；
需要深入阅读或确认外部软件的新功能时再打开相应官方资料。

## 先判断光，再选操作

看原图的光源方向、受光面、阴影、材质和高光余量，确定希望改变的关系：
哪里应更亮，哪里应更暖，哪些物体需要保持可信的颜色。风格名称本身不足以
决定参数；晚霞可以是金橙、红色、紫色或柔和灰调，按画面和用户意图选择。

基础校正解决曝光、色彩解释和妨碍创作的偏色；局部处理解决不同区域的需要。
不必把原有环境光全部中和，也不要靠全局白平衡同时满足混合光下的所有区域。
已有调色不满意时，先识别造成问题的节点并协调它们，避免在偏色上继续叠色。

## 晚霞：一个判断案例

以下是对常见城市/风景照片的处理思路，不是对所有夕阳的定义：

- **天空层次**：近地平线与高处天空可有不同的亮度和冷暖。先判断原图是否
  支持暖色近地平线、较冷的高处天空，再用宽缓渐变建立过渡，避免硬色带。
- **云的体积**：受光云面可偏金橙或珊瑚色，云底仍保留较暗、较冷或中性的
  体积。按亮度分离颜色通常比将所有蓝色转成紫色更适合保留云层结构。
- **地面和建筑**：依据原有受光面决定暖反光的范围。背光建筑可稍暗、较低
  饱和，但保留必要细节；不要让灰墙、道路和所有阴影一起染粉。
- **水面和反射**：根据其对应的天空与光源位置处理；不默认整片水都应橙红。
- **时段可信度**：白天原片可以做傍晚风格，但调色不能生成原本不存在的太阳、
  投影方向或云形。说明是风格化转换，不声称恢复了真实拍摄时刻的夕阳。

局部暖光、冷暖分离和明暗重排是创作判断；这里没有可无条件套用的色温、
色相偏移或 RGB 数值。若全局暖色已符合原片，也不必为了分区而增加节点。

## 对应到 Tinge

| 需要改变的关系 | 可选工具/节点 | 注意 |
| --- | --- | --- |
| 整体曝光、白平衡与明暗 | `tinge_adjust` | RGB gains 为线性乘数，非色温 K；复用 adjustment_id，不反复叠组 |
| 天空与前景分开 | `tinge_edit_preview`，几何 mask、`combine` | 坐标归一化；结合用户选区时核对其修订/哈希与尺寸 |
| 沿高度改变暖光或曝光 | `linear_gradient` + 局部节点 | start 权重 0，end 权重 1；限制到天空，观察楼顶和吊臂 |
| 云层亮部、云底分开 | `log_wheels` / `hdr_zone` / `luma_range` | log_wheels 的 RGB 偏移在编码域；hdr_zone 的 stops/color 为 EV；亮度蒙版阈值在线性域 |
| 单独修改某类颜色 | `hsl` / `hsl_range` | hsl 操作用 HSV，hsl_range 蒙版用 HSL；取样阈值不可直接互换 |
| 有意的阴影/高光色调 | 局部 `split_tone` | 使用编码 RGB 偏移；全局强推容易污染中性色 |
| 检查剪切、通道与范围 | `tinge_stats`，需要时加 scopes | 回答具体疑问时才加载；色域压缩不能代替高光亮度控制 |

精确字段、范围与单位以当前可见 schema 和[算子说明](operators.md)为准。
蒙版按节点的实际输入计算；上游改色后重新检查限定范围。几何羽化可能也淡化
贴着画框的边界，观察四边是否留下一圈未调色区域。用明度分区或柔和限定范围
避免把噪点放大成彩色斑点，检查楼顶光晕、天空断层、云层剪切和前景染色。

在网页中看整体，再用原图/版本对比及 100% 检查边缘。导出前确认修订和输出色彩
空间；默认 sRGB SDR 预览不是专业校准或 HDR 显示验收。保留旧修订，失败回执的
处理、导出和清理授权仍遵循主 Skill。

## 官方阅读入口

资料入口核对日期：2026-10-10。页面可能更新；这些软件的控制数值不能直接当作
Tinge 参数。只沿当前问题阅读相关章节，无需每次加载全部外部资料。

- [Blackmagic Design 官方培训与 The Colorist Guide](https://www.blackmagicdesign.com/products/davinciresolve/training)：
  查找 Colorist Guide、Introduction to Color、Advanced Color、Color Management。
  用于深入学习一级/二级调色、示波器、节点和色彩管理；从官方页面获取教材。
- [Adobe：One Tool, Three Ways — Selective Edits](https://blog.adobe.com/en/publish/2018/08/15/one-tool-three-ways-selective-edits-in-lightroom-classic-cc)：
  包含夕阳天空与城市分别调整的实例，可参考其区域划分思路。
- [Adobe：Lightroom Classic Masking](https://helpx.adobe.com/lightroom-classic/desktop/process-and-develop-photos/masking.html)：
  查阅颜色/亮度范围、蒙版交集与局部明暗、色温调整。Tinge 的现有蒙版能力以
  [功能覆盖表](coverage.md)为准，不假定具备 Adobe 的 AI 天空识别。
